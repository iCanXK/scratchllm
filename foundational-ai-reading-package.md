# Foundational AI Reading Package

Contents:

- `Ilya_30_Papers_Study_Guide.pdf` - formatted study guide.
- `Ilya_30_Papers_Study_Guide.docx` - editable version.
- `download_open_access.py` - downloads openly accessible PDF links only.
- `paper_links.json` - structured bibliography and links.

The list is an unofficial reconstruction. No paper PDFs are included in this archive.

Run the downloader:

```bash
python download_open_access.py
```

It creates a `papers/` directory and skips HTML-only resources.
